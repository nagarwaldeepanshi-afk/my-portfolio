--------------------------------------------------
9. CURSOR INTERACTION
--------------------------------------------------

THIS IS THE MOST IMPORTANT INTERACTION.

The cursor should behave like a physical object moving through paint.

When the cursor moves:

the yellow paint should move away.

It should not reveal a perfect circular hole.

Instead create an organic irregular reveal.

The paint should:

push away
stretch
split
bend
flow
form thin trails
create droplets
slowly return

Fast movement:
larger displacement

Slow movement:
smaller displacement

Stopping:
paint slowly flows back into place

The black technological layer underneath becomes visible through the displaced paint.

The cursor should leave subtle temporary trails.

Create the visual feeling that the user is physically touching wet paint.
